# Microsoft Style — Portuguese (Portugal): дистилляция таблиц

Источник: Microsoft Localization Style Guide, Portuguese (Portugal). Только то, что есть в PDF.

## 1. Канцелярит → разговорные формы (words and phrases to avoid)

| EN | Формально (не надо) | Современно (надо) |
|---|---|---|
| is used to | é utilizado para | serve para |
| is in accordance with | está em conformidade com | obedece, cumpre, satisfaz |
| refer to | fazer referência a | mencionar |
| make a recommendation | fazer uma recomendação | recomendar |
| provide help | fornecer ajuda | ajudar |
| be required | ser necessário | ser preciso |
| are you sure you want to | tem a certeza de que pretende | quer realmente, quer mesmo |
| using (something) | utilizando | com |
| you cannot | não é possível | não pode |
| you can | é possível | pode |

Также: required → **necessário / obrigatório** (не «requerido»); check to / check if / make sure → **certifique-se de que**; convert to → **converter em**.

## 2. Короткие формы и акронимы

- Короткие бытовые слова предпочтительнее длинных, но в pt-PT коротких форм меньше, чем в EN.
- Акронимы в Португалии употребляют чаще, чем в англоязычных странах (IVA, OPA, HDMI, RDIS, ONU, USB, PC): «endereço de Protocolo da Internet» → **endereço IP**.
- Акронимы — капсом, без точек и пробелов. Род — по первому существительному (RDIS ← Rede, ж. р.) или по узусу. Множественное: +s, обязательно, если без него теряется смысл (Connection URLs → URLs de ligação).
- Первое вхождение названия протокола/формата: «protocolo PCTP (Private Communication Technology Protocol)», «formato JPEG (…)»; далее — просто «protocolo PCTP» / акроним.
- Всегда так: ISDN→RDIS, IT→TI, HR→RH, IM→MI, tone dial→MF, VAT→IVA.

## 3. Сокращения (abbreviations)

- Надстрочная буква — с точкой перед ней: número → **n.º**.
- Сокращать: убрать лишние слова → убрать предлоги → точка в конце слова (Mensagem → Msg., Mensagens → Msgs.).
- Ходовые: a/c (ao cuidado), Art.º, cm, col., c/c, CP (código postal), etc., EUR, p.ex., g, h, Hz, kg, km, m, min, mm, N.º/n.º/núm., p./pág./pp./págs., Ref. n.º, s, Sr., Sr.ª/Sra., W.

## 4. Стандартные фразы ошибок

| EN | pt-PT | Пример |
|---|---|---|
| Cannot… / Could not… | Não é possível + инфинитив | Não é possível ativar a aplicação. |
| Failed to… / Failure of… | Falha ao… / Falha de… | Falha ao guardar o ficheiro. |
| …failed to… (в середине) | Subject + não + complemento | O programa de configuração não instalou um ficheiro necessário. |
| Cannot find / Unable to locate | …não encontrado (глагол is/are можно опустить) | Ficheiro não encontrado. |
| Not enough… / Insufficient… | …insuficiente | Memória insuficiente para carregar "%". |
| …is not available / unavailable | …não está disponível (не «indisponível») | O controlador não está disponível. |
| Error/Problem + gerund | Erro/Problema **ao** + инфинитив | Erro ao aceder ao ficheiro. |
| Error/Problem + while | Erro/Problema **ao** + инфинитив | Erro ao aceder ao ficheiro. |
| Error/Problem + in | Erro/Problema **em** (+артикли) | Erro no ficheiro de configuração. |
| Not enough disk space (все варианты) | Espaço insuficiente no disco (+ para…) | Espaço insuficiente no disco para instalar os programas selecionados. |

Стиль ошибок: коротко, без паники, что случилось + что делать: «A palavra-passe está errada, por isso tente novamente.», «Algo correu mal!». Please/Sorry — не переводить.

## 5. Гендер-нейтральность и инклюзивность

| Надо | Не надо |
|---|---|
| representante de vendas | vendedor, vendedora |
| estudante | aluno, aluna |
| Direitos Humanos | Direitos do Homem |
| colegas, pessoal | rapazes; senhoras e senhores |
| familiar, família, adulto, tutores, figura parental | mãe ou pai |
| especialista | guru |
| rede de perímetro | zona desmilitarizada (DMZ) |

- Обобщения — во множественном: os utilizadores, pessoas, indivíduos; никаких «ele(a)».
- Опускать местоимение-подлежащее, если смысл ясен; артикль вместо притяжательного (o documento, не o documento dele); pessoa / indivíduo.
- О реальном человеке — его местоимения (ele/ela/eles ок).
- Доступность: **pessoa com deficiência** (не deficiente / portador de deficiência), **pessoa sem deficiência** (не pessoa normal/saudável), pessoa com mobilidade reduzida (не deficiente motor). Не «que sofre de». Инвалидность не упоминать без необходимости.
- Универсальные глаголы ввода: **Selecione**, не Clique.
- Прописью «e, mais, aproximadamente» вместо & + ~ (скринридеры).

## 6. Пунктуация

- **Запятая:** по правилам pt; перед «e» — нет, кроме перечислений с несколькими «e».
- **Двоеточие:** после него строчная буква. Исключения: Title Case во всей фразе, заголовки разделов, перенос строки после двоеточия.
- **Дефис:** только когда меняет смысл (primeiro-ministro ≠ primeiro ministro); по новой орфографии «fim de semana» без дефисов.
- **En dash (–):** минус (с пробелами) и числовые диапазоны (без пробелов).
- **Em dash (—):** в гайде — только выделение вставного/несущественного элемента. Правило скилла жёстче: не использовать вовсе, перестраивать.
- **Многоточие, точка:** как в источнике. Но: команда в инфинитиве — не полное предложение → без точки, даже если в EN точка есть.
- **Кавычки:** двойные прямые "…" (Selecione "Abrir" e escolha um ficheiro.), не одинарные.
- **Скобки:** без пробелов внутри.
- **Пробелы:** никаких двойных пробелов; пунктуация без пробела перед собой, один пробел после.

## 7. Числа и плейсхолдеры

- 1–10 прописью, остальные цифрами. Круглые: mil, três mil, quatro milhões, 16 biliões.
- В технических, научных текстах, лейблах, заголовках, маркетинге — всегда цифрами.
- Плейсхолдеры: %d/%ld/%u/%lu = число, %c = буква, %s = строка. Выяснять, что подставится, чтобы фраза была грамматична; entity-токены (`<entity type='file'>`) не локализуются, но позиция должна быть естественной для pt-PT (исключение — display-примеры, см. Dev comment).

## 8. Клавиши, шорткаты, регистр

Переводятся: Backspace → Tecla de retrocesso, Ctrl → Control, Down/Up/Left/Right Arrow → Seta para baixo/cima/para a esquerda/para a direita, Spacebar → Barra de espaço, Tab → Tecla de tabulação, Windows key → Tecla Windows, Menu key → Tecla de menu.
Не переводятся: Alt, Break, Caps Lock, Delete, End, Enter, Esc, Home, Insert, Num Lock, Page Down/Up, Pause, Scroll Lock, Shift, Print Screen.

Шорткаты pt-PT отличаются от EN: Select All Ctrl+**T**, Find Ctrl+**L**, Replace Ctrl+**U**, Repeat Ctrl+**R**, Bold Ctrl+**N** (Negrito), Underline Ctrl+**S**, Centered Ctrl+**Y**, Left aligned Ctrl+**E**, Right aligned Ctrl+**H**. Access keys — значимые буквы, ближе к началу слова (Ficheiro, Novo; Guardar, но Guardar Como); консистентность с Office/Windows.

Регистр UI-терминов: следовать EN; однословный EN-термин → многословный перевод с капитализацией значимых слов (Toolbar → Barra de Ferramentas, Save As → Guardar Como; но «e» в середине — строчная). Sentence case в EN → sentence case в pt.

## 9. Copilot-промты (предзаданные промты для AI)

- Тон **неформальный, «tu»**: Cria uma lista…, Formata cada secção…, Propõe uma nova introdução…, Dá-me ideias…
- Ясные конкретные формулировки, естественные вопросы/просьбы; без сленга и жаргона; вежливо.
- Кавычки помогают Copilot понять, что писать/менять — сохранять.
- Entity-токены (`<entity type='meeting'>reunião</entity>`, `<placeholder>…</placeholder>`) не переводить сам токен, содержимое — переводить, позиция — естественная для синтаксиса pt.
- Похожие EN-промты переводить консистентно.

## 10. Разное

- Sentence fragments приветствуются: jogue; oiça a música; consulte a Ajuda; saiba mais sobre.
- display = mostrar (машина показывает) / visualizar (пользователь видит) / apresentar.
- character = **caráter** (мн. carateres), не carácter.
- Wizard: имя с глагола → Assistente **para** + инф. (Assistente para Imprimir Documentos); с существительного/прилагательного → Assistente **de** (Assistente de Impressora).
- Compounds: понимать смысл, число может меняться (Application Log → Registo de aplicações; Server Manager → Gestor de servidor ИЛИ de servidores — по определению).
- Adjectivated nouns: controlador **de** multimédia, computador multimédia, gravador **de** áudio — предлог меняет смысл.
- Род заимствований — по переводу/узусу: a frame (moldura), o patch; непереведённые названия продуктов — всегда o + м. р. ед. ч.
- Версии: Version 2.5 → Versão 2.5; копирайт-строки переводить по Microsoft Terminology.
