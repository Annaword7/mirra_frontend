# UI-тексты на европейском португальском (pt-PT)

База: Microsoft Localization Style Guide — Portuguese (Portugal).
Детальные таблицы (лексика, ошибки, пунктуация, клавиши, Copilot-промты) — в `references/ms-style-pt-pt.md`. Читать при батч-рефакторинге и при любых сомнениях в конкретной формулировке.

⚠️ Не путать с бразильским португальским (pt-BR): в pt-PT — «ecrã», не «tela»; «ficheiro», не «arquivo»; «rato», не «mouse»; «utilizador», не «usuário»; «palavra-passe», не «senha».

## Порядок работы

1. **Определить тип текста:**
   - **UI-строка** (кнопка, лейбл, ошибка, тултип) → компактность, правила глаголов ниже, плейсхолдеры не трогать.
   - **Длинный текст** (онбординг, описание в сторе, email) → тон Microsoft voice: тёплый, разговорный, без канцелярита.
   - **Промт для AI** (предзаданные подсказки) → неформальное «tu» (Cria, Formata, Dá-me), см. references.
2. **Батчи** — рефакторинг строк оформлять таблицей:
   | key | было | стало | почему |
3. **Хорошие строки не трогать** — если строка уже соответствует правилам, в «стало» писать `—` (без изменений).
4. **Сохранять:** плейсхолдеры (`%s`, `%d`, `{0}`, `<entity>`) на осмысленной позиции; длину ±30% от оригинала; регистр по контексту UI.

## Тон (Microsoft voice для pt-PT)

- Ясно, дружелюбно, коротко. Разговорный язык, а не формально-технический.
- Не переводить дословно: понять смысл → написать как носитель написал бы с нуля. Лишнее выкидывать.
- **Обращение:** прямое, но без «você» — вежливое 3-е лицо без местоимения: «Pode copiar…», «Tem de fechar…». Если фраза мутная без местоимения — перестроить (пассив), но «você» всё равно не писать.
- «We» в оригинале можно сохранять как «мы» для теплоты: «retomamos», «ativaremos».
- **Please / Sorry не переводить** — в pt-PT они не нужны.
- Канцелярит → бытовые слова: `é utilizado para → serve para`, `não é possível → não pode`, `tem a certeza de que pretende → quer mesmo` (полная таблица в references).

## Глаголы — главное правило pt-PT

- **Инструкция пользователю** (диалог, подсказка) → императив: «Abra o ficheiro», «Tente novamente».
- **Команда от пользователя машине** (кнопки, пункты меню) → инфинитив: «Abrir ficheiro», «Guardar Como». Без точки в конце.
- **Описание команды/функции** → инфинитив.
- **Процесс** (gerund в EN) → «a + инфинитив»: «A imprimir ficheiro…».
- Тест: если перед EN-фразой можно вставить «Please» — это инструкция (императив); нельзя — команда/описание (инфинитив).

## Анти-AI правило: тире

Em dash (—) в pt-PT — стилистический приём, не грамматика. **Полный запрет:**
- Не использовать «—» вообще: заменять запятой, точкой, двоеточием или перестройкой фразы.
- Запрещены конструкции «X — não é apenas Y» / «X — é mais do que Z» и парцелляция через тире («Rápido — simples — seguro»).
- En dash (–) допустим только как минус и в числовых диапазонах (стр. 3–5, без пробелов).
- Дефис — только когда без него меняется смысл (primeiro-ministro vs primeiro ministro); «fim de semana» по новой орфографии без дефисов.

## Грамматика — выжимка

- **Заголовки/регистр:** повторять регистр английского. Если EN-термин из одного слова, а перевод из нескольких — капитализировать значимые слова: Desktop → Área de Trabalho. После двоеточия — строчная (кроме Title Case и заголовков).
- **Артикли:** минимум артиклей; непереведённые названия продуктов — всегда мужской род ед. ч. с определённым артиклем: «o Office», «o OneDrive». Но «O sistema vai encerrar» — артикль у подлежащего обязателен.
- **Гендер-нейтральность:** нейтральные слова (estudante, representante de vendas), множественное число (os utilizadores), опускать местоимения, «pessoa/indivíduo»; никаких «ele(a)».
- **Доступность:** «pessoa com deficiência», не «deficiente»; «Selecione», не «Clique».
- **Числа:** 1–10 прописью, дальше цифрами; в техтекстах, лейблах и маркетинге — всегда цифрами.
- **Кавычки:** двойные прямые "…" (не одинарные).
- **Предлоги-ловушки:** converter **em**, registar **em**, definir **como**.

## Стандартные шаблоны ошибок

`Cannot… → Não é possível + инф.` · `Failed to… → Falha ao…` · `…not found → …não encontrado` · `Not enough / Insufficient → …insuficiente` · `…is unavailable → …não está disponível` (не «indisponível») · `Error/Problem + gerund/while → Erro/Problema ao + инф.` — полные таблицы в references.
