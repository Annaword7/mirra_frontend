# UI-тексты на испанском (Spanish Neutral, Microsoft voice)

Правила ниже — выжимка из официального Microsoft Spanish (Neutral) Style Guide.
Подробные таблицы (канцелярит → разговорное, ошибки, пунктуация, клавиши):
**обязательно прочитай `references/ms-style-es.md` перед батч-редактурой.**

## Порядок работы

1. Определи тип текста:
   - **UI-строка** (кнопка, метка, меню, тост, ошибка) — коротко, номинально, без лишних глаголов;
   - **длинный текст** (онбординг, e-mail, описание для стора) — разговорный тон, короткие предложения;
   - **промт/инструкция для модели** — точность важнее тона, но правила языка те же.
2. Батчи правок оформляй таблицей: `key | было | стало | почему`.
3. **Хорошие строки не трогай.** Если строка уже соответствует правилам — пометь «OK», не переписывай ради переписывания.
4. Плейсхолдеры (`%s`, `%d`, `{0}`, `%1!s!`) сохраняй и ставь в грамматически верную позицию; `%d` = число, `%s` = строка, `%c` = буква.
5. Длину строки держи в пределах **±30 %** от исходной (UI-вёрстка!). Если правило требует длиннее — предложи короткую альтернативу.

## Анти-AI правило: тире (raya, —)

В испанском длинное тире — стилистический приём, а не грамматическая необходимость
(кроме диалогов в прозе, которых в UI не бывает). Поэтому в UI-текстах:

- **Em dash (—) запрещено полностью.** Заменяй запятой, точкой, двоеточием или перестройкой фразы.
- Запрещены конструкции вида «X — no es solo Y» и парцелляция через тире («Rápido. Simple. — Y gratis»).
- Парные вставки «—como esto—» → запятые или скобки.
- En dash (–) остаётся только как минус (`– 18 °C`, с пробелом после) и в диапазонах (`páginas 204–206`, без пробелов).
- Дефис (-) — только внутри составных слов (`relación calidad-precio`).

## Тон и голос (из стайлгайда)

- **Обращение: «tú»** (неформальное 2-е лицо ед. ч.) — стандарт современного Microsoft voice для потребительских продуктов. «Usted» — только для enterprise/формальных продуктов (Office классический, Cloud & Enterprise, Dynamics). Для одного продукта — один регистр, не смешивать.
- Множественное число — **«ustedes», никогда «vosotros»**; лучше перестроить фразу, чтобы избежать обоих.
- Если рядом сосуществуют строки на tú и формальные — используй **инфинитив или безличную форму** («Elegir una cuenta», «Es posible que…»).
- Пользователь говорит программе — **инфинитив**; программа говорит пользователю — **императив на tú** («Elige», «Escribe», «Prueba otra vez»).
- Не «el usuario puede…», а «puedes…» — обращайся к человеку напрямую.
- Leísmo запрещён: **«lo ayudará»**, не «le ayudará».
- Притяжательные из английского → определённый артикль («guarda el archivo», не «guarda tu archivo»); исключения: «tu PC», «tus PC» (без рода!), пункты UI «Mi PC», «Mis documentos».
- Глаголы вместо отглагольных существительных; **простые времена вместо составных** («después de que termines», не «después de haber terminado»). Будущее — только про реальное будущее.
- Активный залог и императив; допустимы фрагменты предложений («Más información», «Todo listo»).
- Начинать фразу с союза можно («Y, por último…», «O sea que…») — это разговорный тон.
- Сюбхунтив использовать, где требуется; из пары «cantara/cantase» — всегда **«cantara»**.
- «de que» не терять и не добавлять лишнее: «Asegúrate **de que**…», но «Es posible **que**…».

## Регистр и оформление

- **Sentence case везде**: в заголовках, кнопках, командах, диалогах — с заглавной только первое слово и имена собственные («Guardar como página web completa»).
- Национальности, дни, месяцы, языки — со строчной (inglés, lunes, enero).
- Заглавные буквы с ударением обязательны (Éxito, а не Exito).
- Восклицательные знаки из английского в ошибки не переносить; открывающие «¿ ¡» обязательны.
- Гендер-нейтральность: не «el hombre» → «la humanidad», не «vendedor» → «representante de ventas»; переформулируй во 2-е лицо/множественное, не используй «él/ella».
- Доступность: «Selecciona», а не «Haz clic» (работает для любого способа ввода).
