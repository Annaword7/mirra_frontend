# Microsoft Style Guide — японский (дистилляция)

Источник: Microsoft Localization Style Guide, Japanese. Таблицы сжаты, ничего не добавлено.

## 1. Канцелярит и формальные слова → предпочтительные

| Избегать | Использовать | Контекст |
|---|---|---|
| xxx、yyy、および zzz | xxx、yyy、zzz / xxx、yyy、zzz など | перечисления без および |
| ～が可能です | ～できます | can / be able to |
| 推奨します | お勧めします | recommend |
| 古い | 前の、使用していない | old (по контексту) |
| 無効です | 使用できません | invalid |
| 深刻な | 重大な (или переформулировать) | serious, severe |
| ～することにより / ～によって | ～すると、～すれば | by ~ing |
| 適当な | 適切な | ambiguity: 適当 = «любой» |
| 各ファイルごとに | 各ファイルの / ファイルごとに | избыточность |
| ～しても大丈夫です | ～できます | разговорный стиль в UI нельзя |
| いかなる時でも | いつでも | литературный стиль |
| 初心者でも | 初めての方も | дискриминационный оттенок |

## 2. Короткие бытовые слова (short word forms)

| Формально / технично | Бытовое | Примечание |
|---|---|---|
| アプリケーション | アプリ | |
| 選択する | 選ぶ | в связном тексте; в именах кнопок/меню и текстах для разработчиков — 選択 |
| 電子メール | メール | |
| 再度 | もう一度 | |
| 詳細な | 詳しい | |
| 未xx | xx されていません | «не выполнено» |
| 同期する | 最新に保つ | для потребителя |
| 続行する | 続ける | в тексте |

Строки держать максимально короткими: кана/кандзи шире латиницы, текст обрезается.

## 3. Стиль по типу строки

| Тип | Стиль | Пример |
|---|---|---|
| Пояснительный текст, диалоги, сообщения | ですます調 | 設定はいつでも更新できます。 |
| Просьба к действию | …してください。 | もう一度入力してください。 |
| Чекбокс, радиокнопка | である調 / 体言止め | この時計を表示する |
| Меню, кнопки, табы, лейблы, заголовки | 体言止め | 変更箇所の表示 |
| 体言止め: базовая форма ～の～ | не ～の～の～ | オブジェクトの種類を選択 (не …種類の選択) |
| Короткие пункты | добавлять частицу для ясности | 次へ (не 次) |

## 4. Сообщения об ошибках

| Английский шаблон | Японский | Примечание |
|---|---|---|
| Sorry, … | 申し訳ございません。 | отдельным предложением, потом описание |
| Cannot … / Could not … | ～できません | Could not: ～できませんでした допустимо |
| Failed to … | ～できませんでした | |
| Failure of <noun> | ～のエラーが発生しました / ～エラー | |
| Cannot find … / Unable to locate … | ～が見つかりません | |
| Not enough memory / Insufficient memory | メモリが不足しています | メモリ不足のため～できません |
| … is not available / unavailable | ～は使用できません | |
| The password isn't correct, so try again. | パスワードが正しくありません。もう一度入力してください。 | коротко, дружелюбно, с действием |

Тело сообщения — ですます調; заголовок окна и кнопки — 体言止め.
Плейсхолдеры: %d = число, %s = строка; порядок можно менять, если различимы ({1}→{2});
кавычки вокруг плейсхолдера из источника сохранять ('%s' → '%s').

## 5. Местоимения

- Сначала пробуй опустить подлежащее — явное подлежащее часто неестественно.
- we/our → опустить; для ясности 私たち или Microsoft; 弊社 — только очень официально.
- you/your → опустить; по роли: ユーザー, 管理者; клиентский контекст: お客様, ご自分;
  あなた допустимо изредка (напр., «на вашем телефоне»), не должно звучать невежливо.
- Примеры: Remember my password → パスワードを記憶させる;
  We can't find a printer. → プリンターが見つかりません。追加しますか?

## 6. Гендер-нейтральность и инклюзивность

| Использовать | Не использовать |
|---|---|
| 看護師 | 看護婦 |
| 客室乗務員 | キャビン アテンダント / CA / スチュワーデス |
| 保育士 | 保母 |
| 助産師 | 助産婦 |
| 女性警察官 | 婦警 / 婦人警察官 |
| 営業担当者 / 営業スタッフ | 営業マン |
| プライマリ/セカンダリ | マスター/スレーブ |
| 応答しなくなる | ハングする / ハングアップ |
| 親 | 母 or 父 (в обобщении) |
| 障碍のある人 / 障碍がある人 | 障害者 |
| 身体に障碍がある人 | 不具 / かたわ |

彼/彼女 в обобщённых референсах не использовать: переформулировать через роль
(ユーザー, 読者, お客様) или второе лицо. Для реальных людей — их местоимения.
Не «страдает от» инвалидности: без (障碍)を患う / に苦しむ.
Screen reader: писать アンド, プラス, およそ словами вместо & + ~.

## 7. Пунктуация

| Знак | Правило |
|---|---|
| 。、 | стандартные точка и запятая, полноширинные |
| , (полушир.) | разделитель тысяч (2,000 ページ); замена 、в списках при нехватке места |
| : (полушир.) | время (12:27); конец заголовка/пункта как в источнике (フォント:) |
| ‐ дефис | даты/телефоны, перенос английских слов |
| – en dash | не использовать без необходимости |
| — em dash | не использовать без необходимости |
| ～ wave dash | диапазоны нежелательны: заменять на から или полуширинный дефис; 値は 0 から 99 mm |
| ... | многоточие — три полуширинные точки (変更...) |
| “” | текст/символы на экране (кроме UI-лейблов), выделение, имена полей/свойств (“説明” フィールド) |
| [ ] полушир. | ссылки на элементы UI: [OK] をクリックします |
| 「」 | разделы справки/веб, главы документов, вводимый текст (「setup」と入力), строки в файле |
| 『』 | названия книг и документов (『SQL Server 2019 ガイド』) |
| ・ | иностранные имена, страны (トリニダード・トバゴ, エイブラハム・リンカーン) |
| ( ) полушир. | access keys (保存(S)), (R)/(TM), телефоны, пояснение нелокализованного UI: [View] (表示) |
| ? ! (полушир.) | как в источнике; ! можно убрать, если звучит агрессивно |
| / | даты (2011/1/13), пары противоположностей (オン/オフ) |

## 8. Пробелы (полуширинный △)

Вставлять:
- между полноширинным и полуширинным символом: Word△を使用, 第△3△章, Shift△キー
- между английскими словами; между числом и единицей (3△kg) — кроме % и mm
- вокруг + вне UI (Ctrl△+△Alt в документации)
- после ?/! перед следующим полуширинным термом (保存しますか?△Excel を…)

НЕ вставлять:
- после 。、 перед полуширинным; между числом и °
- внутри скобок/кавычек по краям текста: 列 A (タイトル), 「test」
- вокруг слэша: 3/14
- перед ? ! : ... в конце фразы: 更新しますか? / フォント: / その他...
- перед access key в UI: 保存(S); в шорткатах UI: Ctrl+Alt
- между полноширинными: 変換キー (искл.: катакана-композиты ページ△レイアウト; ссылки на главы 「第 2 章△コントロール」)
- 50%, 3 か月 (счётные ka/ko — хираганой или кандзи: 3 か月, 5 個)

## 9. Числа

- Арабские цифры полуширинные: 2,000 ページ, 1.5 インチ.
- Арабские, когда число заменяемо другим: 1 つ, 1 月, (雑誌を) 1 部.
- Китайские, когда незаменяемо/устойчиво: もう一度 (не もう 1 度), (画面の) 一部, 一時的に, 四捨五入.

## 10. Катакана: долгота (長音)

- Суффиксы -er/-or/-ar → длинная гласная: コンピューター, オペレーター, スカラー.
- Иначе: ≤3 знаков (без ッ, ャュョ, ァィゥ) → с ー (キュー, メニュー); ≥4 → без (メモリ, プロシージャ).
- Приставки считать отдельно: プレビュー, サブツリー, インターフェイス.
- Частые исключения: メモリ, コンパイラ, プロセッサ, コネクタ, レジスタ, スケジューラ,
  プログラマ, クリア, ピア, ドア, フロア, エンジニア, ポリシー, ストーリー, サマリー,
  ワークフロー, パススルー, ホットキー, テンキー, メートル, ドル, ビール.
  (Полный список — в исходном PDF; при сомнении сверяться с Microsoft Terminology.)
- Композиты по-английски с пробелом → △ (ダイアログ△ボックス); с дефисом → слитно
  (ダブルクリック); ***bar → пробел перед バー (メニュー△バー, タスク△バー);
  с предлогом in/on → слитно (ログオン, チェックイン).

## 11. Клавиши и шорткаты

- Имя клавиши + キー; латиница: с пробелом (Enter△キー); японское имя: без (変換キー). Без скобок.
- Стрелки: →キー, ↑キー; собирательно 方向キー.
- Шорткаты: полуширинный +, в UI без пробелов (Ctrl+Alt), в документации с пробелами (Ctrl△+△Alt).
- Access key: 保存(S) — без пробела в UI; ?/! ставится между словом и ключом: 警告!(W).
- В документации access keys и символы UI (…, >) опускать: [新規作成] をクリックします。
- Известные отличия шорткатов: Bold = Ctrl+B (не Ctrl+G), Edit Go To = Ctrl+G.

## 12. Элементы UI

- Лейбл в [ ]; тип добавляется после: [この時計を表示する] チェックボックス,
  [メモ帳] ダイアログボックス, [ファイル] メニュー, [追加の時計] タブ,
  [表示名の入力] ボックス, [アドレス] ツールバー, [検索] ウィンドウ.
- Без типа: командные кнопки [OK], команды меню [新規], ссылки, радиокнопки.
- Список в боксе: [タイムゾーンの選択] ボックスの一覧の [(UTC+01:00) …].
- Без скобок: гаджеты (時計ガジェット), иконки в трее (～アイコン), кнопки рамки окна (最小化ボタン).
- Файлы/поля/свойства: латиница без скобок (readme.txt ファイル, Visible プロパティ);
  японское имя — в “” (“表示” プロパティ).
- Нелокализованный UI: добавлять перевод в скобках: [Add/Delete] (追加/削除) ダイアログ ボックス.

## 13. Промты Copilot

- Просьба → ですます調 + してください: …アイデアを一覧にしてください.
- Вопрос → «?» в конце: 会議のゴールとトピックは何ですか?
- Entity-токены: текст внутри тега переводить, атрибут — нет:
  <entity type='meeting'>会議</entity>; [file] → [ファイル].
- Ghost text (<placeholder>…) — в конец предложения:
  以下の一覧を作成してください: <placeholder>海から着想を得た色の名前</placeholder>.
- Похожие промты переводить единообразно; без сленга и жаргона.

## 14. Не локализуется

Товарные знаки; плейсхолдеры ({1}, %s); эскейпы (\n, \r); ключи реестра;
version strings с копирайтом; акронимы (DNS, HTML). Различение версий: 日本語版 / 英語版.
