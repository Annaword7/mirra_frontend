# UI-тексты на японском (Microsoft Voice, ja-JP)

## Порядок работы

1. **Определи тип текста:**
   - UI-строка (кнопка, меню, лейбл, таб) → 体言止め (номинативная фраза): 「変更箇所の表示」, 「次へ」
   - Чекбокс, радиокнопка, заголовок → である調 или 体言止め
   - Сообщение, диалог, описание, онбординг → ですます調 (вежливый стиль)
   - Промт Copilot → ですます調, вопрос заканчивается на «?»
2. **Батчи строк** оформляй таблицей: `key | было | стало | почему`.
   Хорошие строки не трогай — пиши «OK» в колонке «стало».
3. **Сохраняй:** плейсхолдеры ({1}, %s, \n) без изменений (порядок менять можно,
   если различимы); длину ±30% от оригинала (иероглифы шире латиницы — короче лучше).
4. Детальные таблицы (лексика, пунктуация, пробелы, ошибки, клавиши) —
   в `references/ms-style-ja.md`. Читай перед рефакторингом батча.

## Анти-AI правило: тире

В японском тире (— и –) грамматически НЕ нужны — гайд разрешает их «только
при необходимости», на практике в UI это никогда. Поэтому:
- **Em dash (—) и en dash (–) запрещены полностью.** Заменяй на 、 или 。,
  либо перестраивай фразу.
- Запрещены кальки вида «X — это не просто Y» (даже в виде 「Xーそれは…」)
  и парцелляция через тире. Пиши обычными предложениями.
- Диапазоны: «0 から 99» (не «0–99», не «0 ～ 99» в тексте).
- Не путать с 長音符 «ー» (コンピューター) — это часть слова, не тире.

## Тон и грамматика (из гайда, коротко)

- **Стиль:** тёплый, разговорный, краткий. Пиши как для сканирования.
  Не канцелярит: できます вместо が可能です, お勧めします вместо 推奨します.
- **Местоимения опускай.** «You» → чаще всего ничего; при необходимости
  ユーザー / お客様 / ご自分. あなた — только если без него никак и не звучит грубо.
  «We» → опускать; при необходимости 私たち или Microsoft (弊社 — только официоз).
- **Залог:** действие пользователя — актив (ファイルを開きます);
  действие системы — пассив без неодушевлённого субъекта (ダイアログが表示されます,
  не コンポーネントがデバイスを検出します).
- **Просьба к действию:** …してください。 Вопрос о действии: …しますか?
  (не …してもよろしいですか?).
- **Глаголы:** избегай ～させる без нужды; ～を実行します → просто ～します;
  двойных отрицаний нет; жаргона нет (起動します, не 立ち上げます);
  процесс — ～しています / ～中; must/should → ～する必要があります;
  may → ～する場合があります.
- **Вежливые формы** для стандартных просьб: ご確認ください, ご覧ください,
  お問い合わせください, もう一度お試しください (не 再試行してください).
  Без избыточной вежливости (ご使用にならないよう… — нельзя).
- **Скромность в оценках:** без 完璧 / 最高 / 非常に / No.1; факты вместо эмоций.
- **Гендер-нейтральность:** 看護師, 客室乗務員, 保育士, 営業担当者;
  彼/彼女 в обобщениях не использовать — переформулируй или роль (ユーザー).
- **Доступность:** 選択する (не クリックする), 障碍のある人 (не 障害者);
  амперсанды и «+» в тексте писать словами.

## Чек-лист перед сдачей

- [ ] Стиль соответствует типу строки (ですます / である / 体言止め)
- [ ] Ни одного — или –; диапазоны через から
- [ ] Пунктуация 。、 полноширинная; ? ! : ... полуширинные, без пробела перед ними
- [ ] Пробелы: полуширинный между японским и латиницей/цифрами (Word△を使用)
- [ ] Катакана: длинная гласная по правилам (コンピューター, но メモリ)
- [ ] UI-ссылки в [скобках]: [OK] をクリック; ввод текста — в 「」
- [ ] Плейсхолдеры и эскейпы целы
