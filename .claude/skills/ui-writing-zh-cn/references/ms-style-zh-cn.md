# Microsoft Style — упрощённый китайский (zh-CN): дистилляция

Источник: Microsoft Chinese (Simplified) Localization Style Guide. Всё ниже — из гайда, сжато; примеры дословные.

## 1. Канцелярит и формальные слова → разговорные

| Формально (не надо) | Разговорно (надо) | en-US |
|---|---|---|
| 日志 | 博客 / 微博 | blog |
| 倘若 / 假使 / 假若 | 假如 / 如果 | if |
| 若要 | 要 / 如果要 | if you want… |
| 仅是 | 只是 | only |
| 但是 / 不过 | 但 | but, however |
| 总而言之 | 总之 | in conclusion |
| 添加至网络 | 添加到网络 | to: 至 → 到 |
| 邀请至此活动 | 邀请参加此活动 | предлог → глагол |
| 从这个模板创建模块 | 根据这个模板创建模块 | союз/предлог по смыслу |
| 针对企业的 Microsoft Store | 适用于企业的 Microsoft Store | for ≠ 针对 |

Для служебных слов выбирать короткую бытовую форму, как в устной речи (аналог contractions).

## 2. Короткие бытовые слова (word choice)

| en-US | zh-CN | Примечание |
|---|---|---|
| app | 应用 | application — 应用程序 |
| PC | 电脑 | computer — 计算机 |
| select | 选择 | pick — 选取 |
| USB drive / USB flash drive | U 盘 | не «USB 闪存驱动器»; USB 驱动器 — только в контексте Windows To Go |
| maximum / minimum | 上限 / 下限 | вместо 最大/最高限制、最小/最低限制 в неформальном тексте |
| xxx name | xxx名 | 列名/用户名/文件名已存在, не …名称 |

- Допустимые разговорные: 写手、粉丝、方便快捷、量身打造; 菜鸟 — только в игровом контексте.
- Запрещённый сетевой сленг: 给力、山寨、亲、神马、偶、童鞋、酱紫.
- Суперлативы 最好、最强、唯一 — не использовать.
- Идиому источника не переносить пословно: перевести смысл или опустить, если смысл не страдает.

## 3. Стандартные фразы ошибок

Тон: коротко, по-человечески, не по-роботски — что случилось и что делать.

| en-US шаблон | zh-CN шаблон | Примечание |
|---|---|---|
| Cannot find… / Could not find… / Unable to find/locate… | 无法… | 无法删除文件。 |
| Not enough memory / Insufficient memory | 内存不足 | с действием: 内存不足，无法执行此操作。(схема 无法+глагол) |
| …is not available / unavailable | 无法使用… | о человеке: 无法接通 или 没有空 — по контексту |

Эталоны из гайда:

- 密码有误，请再试一次。密码需区分大小写。
- 此产品密钥无效。请核对后再试一次。
- 内存不足，无法处理这个命令。
- 发生错误! 找不到下载的文件，无法创建可启动的 U 盘。
- 一切已准备就绪 (All ready to go)

## 4. Гендер-нейтральность и инклюзивная лексика

| Надо | Не надо |
|---|---|
| 南方人 | 蛮子 |
| 残疾人、残障人士 | 残废（人）|
| 健全人士 | 正常人；健康人 |
| 外国人 | 老外 |
| 农村人 | 乡下人 |
| 社会阶层 | 社会阶级 |
| 村委会主任、村主任 | 村长 |
| 回族 | 回回 |
| 朝鲜 | 北朝鲜 |
| 强势女性 | 母老虎 |
| 大龄青年 | 剩女 |
| 女性化男性 | 娘炮 |
| 搬弄是非的人 | 长舌妇 |
| 秘书 | 女秘书 |
| 众所周知 | 妇孺皆知 |

- Обобщённые 他/她 не использовать: заменить на 其; опустить (该文档, а не 他的文档); назвать роль — 读者、员工、顾客、客户; или 人员 / 个人. Про конкретного человека — его местоимения.
- Доступность: 选择, не 点击 (глагол должен работать для любого способа ввода); 和 / 外加 / 关于 писать словами, а не & + ~ (скринридеры их путают); короткие абзацы и простые фразы — текст должен нормально читаться вслух.
- Инвалидность не упоминать без необходимости; без слов жалости (患病、遭受痛苦).

## 5. Пунктуация: два режима

**Software (UI-строки).** Полноширинные: ，；。、《》. Полуширинные (англ.): : ! ? ( ) < > [ ] … -
**Documentation (доки, сторы, письма).** Полноширинные: ，。、《》“”：；！？. Полуширинные: [ ] / \ - …

| Знак | Software (UI) | Documentation |
|---|---|---|
| Запятая | ， | ， |
| Перечисление | 、: Word、Excel 和 PowerPoint | так же |
| Точка | 。 | 。 |
| Двоеточие | англ. «:» + пробел: 错误: %1; перед полноширинным знаком и “” — без пробела | ：без пробела: 具有以下功能：编辑… |
| Вопрос | англ. «?» + пробел: 是否缺少程序集引用? 是。 | ？без пробела |
| Восклицание | англ. «!» + пробел: 未找到程序集“{0}”! 请转至第 3 步。 | ！без пробела: …Cookie！请稍候片刻。 |
| Кавычки | “” если внутри есть китайский или теги: 应为“人员”项目类型。未找到程序集“{0}”。; "" если внутри только латиница — с пробелом снаружи: 使用 "out" 参数模式标记。 (перед полноширинным знаком пробела нет: 不能是泛型 "Type"。) | всегда “”; внутри них — ‘’: “运行 Setup 出问题时查阅‘诊断和解决问题’一章” |
| Скобки | англ. ( ): к китайскому вплотную — 添加其他元数据(如验证)。; к латинице/цифрам через пробел — 不能是简单 Type (如 string 或 Guid)。 | （） если внутри китайский: （如 OneDrive）, вплотную к тексту; ( ) если внутри только латиница/цифры — с пробелом снаружи: 将 3 和 2 相加 (5)。 |
| Квадратные | [ ] однобайтные | [ ] однобайтные; вложенность — [ ] внутри （）: （不能是简单 Type [如 string 或 Guid]） |
| Многоточие | англ. …: 正在上载…; в отдельных проектах ··· | англ. … |
| Названия | — | 《》 для книг, гайдов, руководств: 《Intune 设置部署指南》 (курсив источника убрать; при гиперссылке 《》 снаружи ссылки/тегов) |

- Названия элементов UI в тексте — в “”: 在工具栏上，单击“编辑”，再单击“替换”。 Имена физических клавиш — без кавычек: 按下 Enter 键。
- Англ. точка «.» остаётся в аббревиатурах, товарных знаках, именах файлов и числах: U.S.A., Hitachi Ltd., CONFIG.SYS, 123.45.
- Слэш / без пробелов: альтернативы 显示/不显示; командные строки; дроби 1/72; даты 1994/1/1. Бэкслэш \ — пути: c:\fruit.

### Тире и дефис

| Знак | Правило |
|---|---|
| Длинное тире —— | **Не использовать**: выглядит как 一. Перестроить фразу; если знак нужен — （）, ： или en dash |
| En dash – | Минус и диапазоны — как в источнике, с пробелами: 1 – 21 |
| Волнистая ~ | Диапазоны: 10 ~ 20%、1 ~ 10MB; при разных единицах — единица у обоих: 1KB ~ 10MB |
| Дефис - | В англ. терминах и составных — как есть |

## 6. Сокращения, числа, плейсхолдеры

- Китайские слова не сокращаются. Дни недели: 周一、周二、周三、周四、周五、周六、周日.
- Имена продуктов и ОС не сокращать: Windows Server 2022 (не Win Server 2022), Windows 11 (не Win 11), Visual Studio 2022 (не VS 2022); Microsoft не сокращать до MS.
- Акронимы — капсом; англ. множественное «s» отбрасывается. HDMI、MB、GB — без перевода.
- AM/PM по времени суток: 凌晨 0:00–5:59 · 上午 6:00–11:59 · 中午 12:00–12:59 · 下午 13:00–17:59 · 晚上 18:00–23:59.
- Цифры — с единицами измерения, в датах (MM-YY-DD), формулах; иначе как в источнике: цифра → цифра, слово → иероглиф.
- Счётные слова — конкретные по существительному, не всегда 个: 两位研究人员, не 2 个研究人员. Версии: Version 4.2 → 版本 4.2.
- Плейсхолдеры: %d / %ld / %u / %lu — число, %c — буква, %s — строка. К числу подобрать счётное слово: %d 位用户在线。
- Если неизвестно, что подставится вместо плейсхолдера, — пробел вокруг него убрать: 单击“完成”按钮以退出[Wizard]。

## 7. Клавиши, шорткаты, регистр хоткеев

- Формат хоткея: `текст(&ЗАГЛАВНАЯ)`, без пробела перед скобкой: 退出(&E)、打印(&I)、重播(&P)、条件 1(&1). Строчную букву источника поднимать до заглавной.
- Хоткей ставить перед знаком препинания: 搜索(&S):、关于(&B)...; в длинной фразе можно перед первой точкой: 我同意(&I)。我已阅读….
- Строка из цифр / одной буквы / знака — как есть, без (&…): 1、100%、800 x 600、S.
- Локализуемые имена клавиш: 向上键、向下键、向左键、向右键、空格键、菜单键、Windows 键. Остальные — как в английском: Alt, Backspace, Enter, Esc, Tab, Shift, Home, End, Insert, Delete, Num Lock, Page Up/Down, Print Screen (Ctrl в полной форме — Control).
- К комбинациям не добавлять 键 / 组合键: 按 Ctrl、按 Ctrl+Alt+Del.
- Стандартные пары «команда — шорткат» не переизобретать: 文件 > 新建 Ctrl+N、文件 > 保存 Ctrl+S、编辑 > 撤消 Ctrl+Z、编辑 > 复制 Ctrl+C、帮助 F1、显示弹出菜单 Shift+F10 и т. д.

## 8. Copilot-промты (предопределённые)

- Промт — естественный вопрос или просьба с глаголом действия; конкретно, без размытых слов: 列出有关为远程团队举办有趣的团建活动的想法.
- Тон разговорный и живой, без машинного стиля; вежливо; без сленга и жаргона: 给我一些关于新团队破冰活动的想法.
- Кавычки “” показывают Copilot, что именно писать/менять: 创建一个“…”列表.
- Entity-токены — плейсхолдеры, не локализуются; позиция токена — по синтаксису китайской фразы; вокруг тегов ставится пробел (требование движка): 提议一个新的 <entity type='file'>文件</entity> 简介; <entity type='meeting'>会议</entity> 中有哪些未解决的问题? Исключение: если промт — display-текст и Dev-коммент велит переводить.
- Похожие промты переводить единообразно; следить за пунктуацией и грамматикой — от этого зависит качество ответа.

## 9. Тон — краткая памятка

- 你, не 您; местоимения и притяжательные опускать, если смысл не страдает; система о себе — 我们.
- Переписывать по смыслу, не пословно: 彰显你的个性 (не 反映你的个性); 尽善尽美的工作和娱乐体验。 (не 最棒的工作和娱乐。); неудачное в китайском контексте — опустить (Drum roll… → 请稍等…).
- 都 значит «все»: 3 条记录都已创建成功。 Экономить 的: 使用新功能（例如计算字段和数据宏）, не 新的功能…许多的相同的操作.
- Фрагменты вместо длинных предложений: 请执行以下步骤：→ 步骤如下：; 请参阅下面的图像：→ 如图所示：; 如果希望继续进行，请单击… → 如要继续，请单击…
- Прогресс — 正在… (正在上载…); заголовки «Using…» — без 正在 (使用协作功能).
- Полуформально и дружелюбно, как другу; без 不…就不…、不是不…; свысока с пользователем не говорить.
