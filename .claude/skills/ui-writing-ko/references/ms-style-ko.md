# Microsoft Korean Style Guide — дистилляция

Источник: Microsoft Localization Style Guide for Korean. Все примеры — из гайда.

## 1. Канцелярит → предпочтительные формы (words and phrases to avoid)

Не наращивай 수행/실행/제공 на отглагольные существительные (작동, 동작, 설치, 제거, 검색, 감사…) — используй сам глагол. Избегай трудных ханча-выражений, бери повседневные слова.

| Было | Стало |
|---|---|
| 새로 고침 수행에 실패했습니다. | 새로 고치지 못했습니다. |
| 알맞은 암호를 제공하십시오. | 알맞은 암호를 입력하세요. |
| …개요를 참조를 하십시오. | …개요를 참조하세요. |
| 기능들에 대한 개요를 제공합니다. | 기능을 간략하게 설명합니다. |
| [예]를 클릭하여 제거를 수행합니다. | [예]를 클릭하여 제거합니다. |
| 이 절차들을 수행하여 암호를 변경하십시오. | 암호를 변경하려면 다음 단계를 따르세요. |
| 계속하기를 원하십니까? | 계속하시겠습니까? |
| 앱을 가져오시겠습니까? (Get the app?) | 앱을 받을까요? |

Частые ошибки пословного перевода:

| Было | Стало |
|---|---|
| 이러한 앱과 모든 정보가 PC에서 제거됩니다. | 다음의 앱과 앱의 모든 정보가 PC에서 제거됩니다. |
| 이 앱에 대한 사용 권한 설정 | 이 앱의 사용 권한 설정 |
| 데이터에 대한 추가 로밍 요금에 대해 신경 쓰지 않으려면 | 추가 데이터 로밍 요금을 내지 않으려면 |
| PowerPoint에서 ^1이(가) 검색되지 않습니다. | ^1을(를) 찾을 수 없습니다. |

## 2. -세요 вместо -십시오

Для Microsoft voice — окончание **-세요** (естественно, разговорно). **-십시오** только в EULA и юридических текстах.

| Формально | Предпочтительно |
|---|---|
| 다음 단원을 참조하십시오. | 다음 단원을 참조하세요. |
| 파일을 사용하지 마십시오. | 파일을 사용하지 마세요. |

## 3. Короткие бытовые слова (short word forms)

Неестественные выражения меняй на привычные повседневные:

| en-US | Корейский |
|---|---|
| E-mail address | 메일 주소 |
| Online store | 온라인 스토어 |
| Home page | 홈페이지 |
| accessibility | 접근성 (не 내게 필요한 옵션) |
| trusted connection | 신뢰할 수 있는 연결 (не 트러스트된 연결) |

## 4. Стандартные фразы ошибок

Стиль: полные формы -니다 с точкой в конце, даже если в английском двоеточие. Если английский — не предложение, а фраза, допустима краткая форма без точки (…오류 발생). «be»-эллипсис английского разворачивай полностью. Единообразие важнее буквальности.

| English | Перевод |
|---|---|
| Cannot… / Could not… | ~할 수 없습니다. (прошедшее время не нужно) |
| Failed to… / Failure of… | ~하지 못했습니다. (сущ. «failure» → 오류 или 실패 по контексту) |
| Cannot/Could not/Unable to find… | ~찾을 수 없습니다. |
| Not enough / Insufficient memory | 메모리가 부족합니다. |
| …is not available / unavailable | ~(사용)할 수 없습니다. |
| An error occurred while/when…, Error while… | ~하는 동안 오류가 발생했습니다. (именно 동안, не ~하는 중) |
| Something bad happened! | 문제가 발생했습니다. |

Примеры пунктуации:
- Specified proxy address ""{0}"" is invalid: {1} → 지정한 프록시 주소 ""{0}""이(가) 잘못되었습니다. {1}
- Error Accessing URL Address → URL 주소에 액세스하는 동안 오류 발생 (фраза — без точки)
- …database: [2] → …데이터베이스를 읽는 동안 오류 발생: [2] (двоеточие + плейсхолдер — как в источнике)
- Not enough memory. Continue without Undo? → 메모리가 부족합니다. 취소하지 않고 계속하시겠습니까?

## 5. Гендер-нейтральность и инклюзивная лексика

| Используй | Не используй |
|---|---|
| 배우, 작가 | 여배우, 여작가/여류작가 |
| 영업 담당자 | 세일즈맨 |
| 성소수자 | 호모/게이 |
| 승무원 | 스튜어디스 |
| 학부모 | 학부형 |
| 한부모 가족 | 편부모 가족/결손가족/미혼모/미혼부 |
| 부모 | 엄마/아빠, 어머니/아버지 |
| 의사, 교사 | 여의사, 여교사 |
| 장애인 | 불구자/장애자 |
| 비장애인 | 정상인/일반인 |
| 기본/보조 | 주인/노예 (master/slave) |
| 경계 네트워크 | 비무장지대(DMZ) |
| 시골 사람 | 촌놈 |
| 스님 | 땡중 |

Местоимения 그/그녀 в generic-тексте не использовать: перестрой фразу, опусти местоимение, убери притяжательность (문서, не 그의 문서) или назови роль (회원, 독자, 직원, 고객, 클라이언트). О реальных людях — их предпочитаемые местоимения допустимы. Не упоминай инвалидность без необходимости; не 고통을 받는/아픈. Select = 선택하다, не 클릭하다 (работает для любых способов ввода). Спецсимволы &, +, ~ выписывай словами: 그리고/및, 더하기/플러스, ~에 대한 (скринридеры).

## 6. Пунктуация, кавычки, скобки

- Предложения на -세요/-합니다 заканчиваются **точкой**, независимо от английского двоеточия/точки с запятой.
- **UI-термины в софт-строках** — в квадратных скобках [ ]: [추가]를 클릭합니다. Если в источнике двойные кавычки — сохраняй кавычки: \"예\"를 클릭합니다. Имена программ и «제어판» берутся в [ ] только когда употреблены как команда для запуска.
- **В документации/справке** — то же оформление, что в источнике (bold → bold: **App Services**를). Italic для корейского текста убирается → заменяй на bold/подчёркивание/[ ].
- Составные слова пишутся слитно: 구름다리(O) / 구름 다리(X); пробел меняет смысл (작은아버지 «дядя» vs 작은 아버지 «невысокий отец»).
- Плюрализация: суффикс 들 обычно опускается без потери смысла.

## 7. Сокращения и акронимы

- Не сокращать: Microsoft → MS, Visual Studio → VS (в именах продуктов), имена ОС. Win Server(X) → Windows Server(O), VS 2022(X) → Visual Studio 2022(O).
- Дни недели сокращаются: 월, 화, 수, 목, 금, 토, 일. Месяцы — нет.
- Аббревиатуры без пробелов внутри; неразрывный пробел, чтобы буква не уезжала на новую строку.
- Формат акронимов: **английский акроним первым**, расшифровка в скобках без пробела перед ними:
  - есть устоявшийся корейский перевод → USB(범용 직렬 버스), IIS(인터넷 정보 서비스), DN(고유 이름);
  - нет → MMC(Microsoft Management Console), ODBC(Open Database Connectivity);
  - к именам продуктов правило не применяется: Microsoft Information Protection (MIP) — как есть.
- В заголовке расшифровку не давать. Буквы акронима — прописные: Vpn quarantine → VPN 격리.
- Английское множественное -s у акронимов отбрасывается: 몇몇 IFSs → 몇몇 IFS; three OEMs → 세 OEM.

## 8. Числа и плейсхолдеры

- %d/%ld/%u/%lu = число, %c = буква, %s = строка.
- **Нумерованные** плейсхолдеры (%1, %2, {0}, {1}) можно переставлять под корейский синтаксис: Setup run at %1 on %2 → %2의 %1에서 설치 프로그램이 실행됩니다. **Ненумерованные** (%s … %s) переставлять нельзя — используй скобки: %s(위치: %s)에서….
- X of Y → слэш: Step %d of %d → %d 단계/전체 %d 단계; Page %d of %d → %d/%d 페이지.
- После %d добавляй **счётное слово** без пробела: %s 문자열은 %d자 이상이어야 합니다; %d개의 문서; %d일 후에는. Порядок слов можно менять: line %d → %d 줄.
- **Двойные частицы** после плейсхолдера: 은(는), 이(가), 을(를), 과(와), (으)로. Примеры: '%1!s!'을(를) 찾을 수 없습니다; {1}과(와) 같아야 합니다; {1}(으)로 이동하는 동안; {0}은(는) 이미 사용 중입니다; %1!s!이(가) 발급한 인증서가….

## 9. Клавиши и шорткаты

- К одиночной клавише добавляй слово 키 через пробел: Enter 키, Shift 키, F1 키. К комбинациям 키 НЕ добавляется: Ctrl+Alt+Del을 누르세요.
- В софт-строках клавиши в угловых скобках: <Enter> 키, <Ctrl+Alt+Del>; в документации — без скобок. SPACEBAR → 스페이스바 (без < > везде).
- Первая буква имени клавиши прописная: Shift 키, Esc 키.
- Access keys: в корейском «(& + прописная буква)» в конце строки: OK → 확인(&O); Require 256-bit encryption → 256비트 암호화 필요(&2); MIME → MIME(&M). Если строка — только число, оставляй как есть: 1, 100%, 800 x 600 (без (&1)).
- Ходовые переводы: 도움말 창 (F1), 취소 (Esc), 다음 활성 응용 프로그램으로 전환 (Alt+Tab), 새로 만들기 (Ctrl+N), 열기, 닫기, 저장, 다른 이름으로 저장 (F12), 인쇄, 실행 취소 (Ctrl+Z), 잘라내기/복사/붙여넣기, 모두 선택, 찾기/바꾸기, 기울임꼴/굵게/밑줄, Alt+스페이스바, Ctrl+백스페이스.
- Стрелки: 위쪽/아래쪽/왼쪽/오른쪽 화살표 키; Home 키, End 키.

## 10. Глаголы, времена, герундий

- Continuous-герундий → ~하는 중 или ~하고 있습니다: Saving text file… → 텍스트 파일을 저장하는 중…; Now saving temporary file → 임시 파일을 저장하고 있습니다.
- Герундий в заголовке — не continuous: Completing the New Connection Wizard → 새 연결 마법사 완료.
- Базовое время — настоящее; времена по контексту источника. "could not" в прошедшее не переводить.
- has the wrong version → 버전이 잘못되었습니다 (has → is).

## 11. Sentence fragments

Кратко и грамматично; английскую «притяжательную» модель меняй на бытийную корейскую:

| en-US | Длинно | Фрагмент |
|---|---|---|
| Here's how. | 다음을 실행하려면 이 방법을 사용하십시오. | 방법 / 다음과 같이 하세요. |
| You may not have appropriate rights. | 필요한 사용 권한을 가지고 있지 않을 수 있습니다. | 필요한 권한이 없을 수 있습니다. |
| …already has a one-way trust relationship | 트러스트 관계를 이미 갖고 있습니다 | 트러스트 관계를 이미 맺고 있습니다 |

## 12. Copilot-промты (predefined prompts)

- Тон дружеский, разговорный, не машинный: окончания **해 줘**, **해줄래?** (아이디어를 나열해 줘. / 제안해 줄래?). Обращение к пользователям: 여러분.
- Ясно и конкретно, без сленга и жаргона; вежливо.
- Кавычки сохраняем — они говорят Copilot, что писать/менять.
- Entity-токены (<entity>, <placeholder>, [file]) обычно не локализуются, но их **позиция** должна быть синтаксически естественной; если промт — отображаемый пример (см. DevComment «Translate [file]»), содержимое токена переводится: <entity type='meeting'>모임</entity>에서 해결하지 못한 문제가 뭐였지?
- Похожие английские промты переводи единообразно.
