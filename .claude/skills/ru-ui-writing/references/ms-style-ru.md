# Справочник: Microsoft Russian Style Guide — таблицы

Дистилляция официального Russian Localization Style Guide (Microsoft).
Читать при рефакторинге батчей строк и спорных словах.

## Канцелярит → нормальные слова

| Избегать | Использовать |
|---|---|
| в данный момент, в текущий момент | сейчас |
| впоследствии | затем, потом, далее, позже |
| вывести на печать | распечатать |
| вывести на экран | показать |
| выполнить действия | сделать |
| вышеуказанный | указанный, этот |
| задать конфигурацию | настроить |
| идентифицировать | определить, найти, указать |
| иметь место | быть, возникать |
| иметься | есть / без глагола («У проблемы три решения») |
| нижеперечисленные | указанные ниже, следующие |
| обеспечивает возможность | позволяет, помогает |
| обратитесь к (о документах) | см., вы можете найти в… |
| пользователи | люди (где уместно) |
| предварительно | сначала, для начала, раньше |
| присутствовать / существовать | быть, находиться / без глагола |
| данный (о «this») | этот |
| персонализировать | настроить (для широкой аудитории) |

## Формальные союзы и предлоги → живые

| Избегать | Использовать |
|---|---|
| вследствие того, что; поскольку | так как, потому что, из-за того что |
| в целях, с целью | чтобы, для |
| однако | но |
| вследствие | из-за, так как |
| посредством | с помощью / не переводить |
| касательно, относительно | о |

## Отглагольные существительные → глаголы

- Чтобы установить подключение → Чтобы подключиться
- Чтобы выполнить удаление → Чтобы удалить
- отменить операцию удаления → отменить удаление
- Опасные существительные: операция, процедура, действие. Если после них
  стоит ещё одно отглагольное существительное — удалять.
- Глагол «выполнить» почти всегда заменяется конкретным глаголом действия.

## Короткие бытовые слова

| en | Вместо | Пиши |
|---|---|---|
| email | электронная почта | почта |
| email (message) | сообщение электронной почты | письмо, сообщение |
| user account | учетная запись пользователя | учетная запись (если ясно) |
| spam | нежелательная почта | спам |
| hacker | злоумышленник | хакер |
| hard disk | жесткий диск | диск |
| ID | ИД | идентификатор, код |

## Стандартные фразы ошибок

| en | ru |
|---|---|
| Cannot… / Can't… | Не удается… / …не может… / Невозможно… (не «нельзя» — грубо) |
| Failed to… / Could not… / Unable to… | Не удалось… |
| …failed. | Сбой… («Сбой удаления.») |
| Do you want to…? | Вы хотите…? |
| Are you sure you want to…? | Вы действительно хотите…? |
| …is not available | …недоступен / Запрошенные ресурсы недоступны |
| An error occurred while… | Произошла ошибка при… |
| An error was detected… | Обнаружена ошибка при… |

Стиль ошибок: без восклицательных знаков; пассив, если актив звучит
как обвинение («Копия ещё не активирована», не «Вы не активировали»).
Дружелюбно: «Это неправильный пароль. Попробуйте еще раз. Не забывайте
про регистр.» / «Кажется, у нас проблема.»

## Гендер-нейтральность

- «Я принимаю условия соглашения», не «Я согласен».
- «Мною изучена политика…», не «Я ознакомился…».
- Множественное число вместо «он»: «Разработчикам нужен доступ… им не нужен…».
- Без местоимений перед существительными: «документ», не «его документ».
- С плейсхолдером имени: «Пользователь {user} ответил…» или «{user} ответил(-а)…».
- Роль вместо пола: читатель, сотрудник, клиент.

## Инклюзивная лексика

| Не так | Так |
|---|---|
| бомж | бездомный |
| гуру | эксперт, специалист |
| ребята; дамы и господа | коллеги; все |
| гастарбайтер | трудовой мигрант |
| инвалид; человек с ограниченными возможностями | человек с особыми потребностями |
| нормальный, здоровый (о людях без инвалидности) | человек без особых потребностей |
| язык жестов | жестовый язык |
| щелкните, нажмите (в инструкциях) | выберите (работает для всех способов ввода) |

## Пунктуация

- Тире: только по грамматике, с пробелами, неразрывный пробел перед тире.
  Не копировать em dash из английского источника.
- Дефис — не замена тире. Диапазоны: 10–20 (en dash без пробелов).
- Минус: en dash (1 – 2 = –1).
- Многоточие: символ … (U+2026).
- Кавычки: «ёлочки»; вложенные — "прямые" («кнопка "Готово"»).
- После двоеточия — строчная буква (кроме списков и прямой речи).
- «Внимание!» с восклицательным знаком, «Примечание.» с точкой (не двоеточие).
- «например» — запятые с обеих сторон, кроме начала/конца обособленного
  оборота: «единицы, например дюймы или сантиметры».
- «по умолчанию» запятыми не выделяется.
- Точка со скобками: (внутри, если скобки — целое предложение.);
  снаружи, если часть предложения (вот так).
- Избегай точек с запятой: два коротких предложения лучше.
- Двоеточие перед маркированными списками.

## Неразрывные пробелы

Разделитель тысяч (10 000), перед % (10 %), число+единица (5 кг, 5 °C),
инициалы (А. А. Сидоров), сокращения (и т. д.), перед тире (Файл — это…).

## Сокращения

Только общепринятые: стр., рис., см., и т. д., и т. п., ч, мин, с, г.,
мес., нед., дн., КБ, МБ, кбит. Прочее не сокращать произвольно.
С числовыми плейсхолдерами сокращения спасают грамматику:
«осталось %1 дн.» вместо «%1 дней(-я)».

## Числа и плейсхолдеры

- Однозначные числа — словами или цифрами; в начале предложения — словами.
- С единицами измерения и валютой — цифрами.
- Строки с числом: перестраивай под любые значения —
  «Обнаружено папок: %1» / родительный падеж: «не менее %1 секунд».
  Формы вида «Найдено %1 файл(-а, -ов)» запрещены.

## Клавиши и шорткаты

- Названия клавиш капсом: ВВОД, ПРОБЕЛ, СТРЕЛКА ВНИЗ, ESC, CTRL+TAB.
- «нажмите клавиши», не «нажмите сочетание клавиш»; плюс без пробелов.
- клавиша Windows, клавиша меню — строчными (описательные названия).

## Регистр

- Sentence case в заголовках: только первое слово с заглавной.
- Режимы и мастера — строчными (режим конструктора), но названия продуктов,
  совпадающие с нарицательными, — с заглавной (откройте Календарь).
- UI-элементы при переводе повторяют регистр источника:
  «Нажмите кнопку «Изменить»».

## Промты для AI-фич (из раздела Copilot)

- Начинать с инфинитива, существительного или императива на «ты»-тоне
  без обращения: «Составь список идей…», «Идеи для встречи-знакомства…».
- Без «вы», без канцелярита, без слов-пустышек («Дай мне идеи» → «Идеи…»).
- Кратко; кавычки помогают модели понять, что писать/менять.
- Плейсхолдеры-сущности `<entity>` не переводятся (если нет DevComment),
  но позиция в предложении должна быть грамматичной.
